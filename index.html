Core Concepts

State-first, spatial, auditable cognition.

  • State Code — A screenshot (or grid) that encodes state + constraints + affordances, sufficient to resume.
  • Spatial is the Interface — Boxes, color, emptiness, and boundaries enforce rules without negotiation.
  • Impossible States — Must never be rendered. If shown, the system is broken.
  • Learning = Loss — Real learning removes future options (irreversible specialization).
  • Screenshot Ingestion — Cross-model handoff via shared visual grammar (state transfer, not chat).
📌 Minimal “No-BS” Rule Set
  • Externalize state first; narration is optional and can be banned.
  • Blank cells = unresolved possibility.
  • Fixed cells = committed state.
  • Advantage implies cost (disadvantage increases too).
