# EmoGro

**Experimental concepts for state-first, spatial, auditable interfaces.**

EmoGro is a small research and prototyping project exploring how software can externalize state visually rather than relying on narration or hidden context.

## Concepts

- **State code** — a visual representation that captures state, constraints, and available actions.
- **Spatial interface** — layout, boundaries, and empty space communicate system rules.
- **Impossible states** — invalid combinations should never be rendered.
- **Irreversible learning** — specialization reduces future options instead of only adding capabilities.
- **Visual handoff** — state can be transferred between systems through a shared visual grammar.

## Prototype

The repository currently contains a lightweight static concept hub in [`index.html`](./index.html).

It is intentionally small: the goal is to document and test interface ideas before committing to a larger implementation.
